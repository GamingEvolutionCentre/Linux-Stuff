## 🚨 🚨 OhMyZsh 🚨 🚨
</div>
<br>

<p align="center">
 <img src="https://ohmyzsh.s3.amazonaws.com/omz-ansi-github.png" alt="Oh My Zsh">
</p>

- Oh My Zsh is an open source, community-driven framework for managing your zsh configuration.
<br>

💥 Themes
default theme is `agnosterzak` installed.
> Change theme
- themes are keep in `~/.oh-my-zsh/themes`. There is 150 themes to choose from pick one then 
- edit `~/.config/zsh/.zshrc` . Look for ZSH_THEME="desired theme"

💥 Audio
- This script will install pipewire.

💥 SDDM Themes
- If you opted to install SDDM.
- You can select theme by editing [metadata](./metadata.desktop) (`/usr/share/sddm/themes/sddm-theme/metadata.desktop`).

Just edit this line:
```bash
ConfigFile=Themes/cyberpunk.conf
```
