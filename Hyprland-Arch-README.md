# 🚨 🚨 Installation 🚨 🚨
<br>

## 🚨 Install 🚨
</div>

> [!IMPORTANT]
> install a backup tool like `timeshift`. and Backup your system before installing hyprland using this script (HIGHLY RECOMMENDED)

💥 Bash or Zsh shell install
> If you are using BASH OR ZSH SHELL do the following

- You can use this command to automatically clone the installer and ran the script for you

```bash
curl -fsSL https://github.com/GamingEvolutionCentre/Arch-Hyprland | sh
```
<br>

💥 Fish shell install
> If you are using FISH SHELL do the following

- You can use this command to clone this repo and it will download by using git. Change directory, make executable and run the script

```bash
git clone https://github.com/GamingEvolutionCentre/Arch-Hyprland.git
cd ~/Arch-Hyprland
chmod +x install.sh
./install.sh
```
<br>

💥 Themes
default theme is `agnosterzak` installed.
> Change theme
> Auto Change
- to change the theme, `SUPER SHIFT O` (The Windows key or Command key (often with a logo) + shift key + o), choose desired theme, and close and open terminal.
> Manual Change
- manually edit `~/.zshrc` . Look for ZSH_THEME="desired theme"
